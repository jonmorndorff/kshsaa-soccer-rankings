Opponent-adjusted performance

Scores are calculated iteratively using opponents and opponents' opponents. Goal margins are capped at five to reduce incentives to run up scores. Close losses to stronger opponents can receive higher performance credit than blowout losses. A loss never counts as a win.

Ratings are model estimates on a 0–100 scale, not probabilities of winning. Small sample sizes can cause volatile rankings. All classes are ranked together before filtering by classification.

Official source policy

Only completed matches reported on KSHSAA.org should enter the published rankings. Each imported game must include its source URL from that domain.

The website loads published season data automatically when available. Manual imports are stored only in your browser.
